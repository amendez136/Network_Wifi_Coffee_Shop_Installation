## Network+ WiFi Coffee Shop Installation Project

### Project Overview
Designed a secure and scalable Wi-Fi network infrastructure for a coffee shop environment as part of a networking course project. The network was designed to support employees and guests while maintaining performance, security, and network segmentation through industry-standard networking practices.

### Key Skills
- Network Design & Planning
- Wireless Networking (Wi-Fi 6)
- VLAN Configuration
- IP Addressing & Subnetting
- Network Security
- Quality of Service (QoS)
- Technical Documentation

### Project Highlights
- Designed a wireless network to support 40+ concurrent users.
- Implemented VLAN segmentation to separate employee and guest traffic.
- Configured guest network isolation to enhance security.
- Developed an IP addressing and subnetting plan.
- Recommended WPA3 security controls for wireless access.
- Applied QoS policies to prioritize critical network traffic.
- Created network topology diagrams and infrastructure documentation.

### Technologies & Concepts
- Wi-Fi 6 (802.11ax)
- VLANs
- WPA3 Security
- DHCP
- NAT
- Quality of Service (QoS)
- IP Subnetting
