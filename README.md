# Network+ WiFi Coffee Shop Installation Project

## Project Overview
This project was created as part of a college networking course. The goal was to design a secure and reliable wireless network for a coffee shop environment.

## Objectives
- Design a wireless network infrastructure
- Select appropriate networking equipment
- Create an IP addressing plan
- Implement basic security measures
- Provide internet access for employees and customers

## Skills Demonstrated
- Network Planning
- Wireless Networking
- IP Addressing
- Network Security
- Technical Documentation

## Deliverables
- Network design presentation
- Equipment recommendations
- Network topology diagrams
- Security recommendations
